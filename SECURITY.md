# Security and responsible disclosure

Please report security issues privately to Townsend Precision Labs Ltd before opening a public issue. Do not attach customer routines, drawings, reports, serial numbers, credentials or other controlled information.

When reporting a problem, include the affected release or commit, PC-DMIS version, Windows version, reproduction steps and a minimal synthetic example where possible.

This validation-build software controls report extraction and file creation. Users remain responsible for validating generated inspection records before production or contractual use.
